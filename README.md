# TikTok Video Downloader

Ứng dụng desktop tải video TikTok từ liên kết video.

## Chạy ứng dụng

```bash
python main.py
```

## Tính năng

- Dán link TikTok và tải video về
- Giao diện desktop thân thiện, dễ nhìn
- Chọn thư mục lưu riêng
- Hiển thị tiến trình tải trực quan

## Cài đặt phụ thuộc

```bash
pip install yt-dlp
```
